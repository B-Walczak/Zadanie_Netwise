Krótka aplikacja webowa pobierająca ciekawostki o kotach z zewnętrznego API (catfact.ninja) i zapisująca je asynchronicznie do lokalnego pliku tekstowego. Projekt demonstruje praktyczne zastosowanie wstrzykiwania zależności (Dependency Injection) do obsługi operacji na plikach oraz posiada responsywny interfejs w trybie Dark Mode z systemem wyskakujących okienek (modal).

Technologie:

C# / .NET 8

ASP.NET Core Blazor (Interactive Server)

REST API (komunikacja przez HttpClient)

HTML5 / CSS3
